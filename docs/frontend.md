# Angular UI

UI сохраняет операции, историю, atVersion и повтор команды с тем же Idempotency-Key.
Основная карточка читает только read model. Ответ команды хранится отдельно и не подменяет
карточку чтения: после commit write side может быть новее.

## Async CQRS

Экран показывает статус polling-обработчика и кнопки паузы/возобновления текущего backend.
Показываются write-side версия из comparison, версия проекции и число pending events.
Состояния подписаны как «Проекция догоняет» и «Модели совпадают». Пауза не кластерная.

После успешной команды UI выполняет отдельный GET. Если проекция отстаёт или отсутствует,
новые операции этого кошелька временно отключаются: expectedVersion берётся только из
показанной read model. Backend продолжает принимать команды независимо от этой блокировки UI.
PROJECTION_NOT_READY отображается как «Кошелёк создан, проекция ещё не готова».

## Надёжность клиента

HttpClient получает ответы текстом, затем parseSafeJson проверяет безопасный диапазон
Java long до помещения данных в signals. Деньги форматируются через BigInt. Команды не
повторяются автоматически. Generation counters и флаг in-flight не позволяют ответу старого
кошелька или пересекающемуся polling-запросу заменить актуальное состояние.

Comparison и read side обновляются управляемым интервалом без WebSocket. При уничтожении
компонента таймер очищается. История сохраняет пагинацию 20 элементов и защиту от устаревших
ответов. В localStorage находятся только UUID недавних кошельков.

## Запуск

    cd frontend
    npm ci
    npm start

Dev proxy отправляет /api/** на http://127.0.0.1:28741. Production-сборка:
npm run build. Тесты и browser automation не добавляются и не запускаются.

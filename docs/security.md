# Безопасность учебного кошелька

Этап рассчитан на локальный запуск без авторизации. Не добавлять Spring Security или внешние
системы доступа в рамках учебной задачи; не публиковать API в недоверенную сеть.

SQL параметризован. EventSerializer использует явный реестр event_type/schema_version.
Wallet восстанавливается из событий, а не из данных клиента или read model. Повреждённые и
неизвестные факты не пропускаются.

ProblemDetail не раскрывает SQL, stack trace, credentials и payload. Пароли передаются через
DB_URL/DB_USERNAME/DB_PASSWORD; .env не коммитится. Учебные wallet/wallet применимы только
к локальной PostgreSQL.

Технические endpoints паузы управляют только текущим экземпляром и не являются механизмом
авторизации или кластерной блокировки. Нет endpoint удаления событий, receipts, read model
или volume; приложение не очищает БД и не выполняет backfill при GET.
